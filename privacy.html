Privacy Policy

Last updated: October 15, 2026

This policy describes how the Oddly Physics Tool (the "Tool") handles data. The Tool is a private program used only by the operator of the Oddly Physics YouTube channel to publish its own videos and review its own channel statistics.

Who uses the Tool

Only the channel operator signs in to the Tool, using the Google account that owns the Oddly Physics channel. The Tool is not offered to other users and never accesses other people's Google or YouTube accounts.

Data the Tool accesses

Through YouTube API Services, the Tool requests the following permissions for the operator's own account:

  • Upload videos (youtube.upload): to upload videos rendered by the Tool to the operator's channel.
  • View the YouTube account (youtube.readonly): to list the channel's own videos and their public statistics.
  • View YouTube Analytics reports (yt-analytics.readonly): to read the channel's own performance reports.

How data is used and stored

  • Data is used only to upload the operator's videos and to show the operator their own channel statistics.
  • The sign-in token and any statistics are stored only on the operator's own computer. They are not sent to any other server.
  • Data is not sold, shared with third parties, or used for advertising.
  • The Tool does not collect any data about viewers of the channel beyond the aggregated reports provided by YouTube Analytics.

Google API Services

The Tool uses YouTube API Services. By using the Tool, the operator is bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time on the Google Account third-party connections page. Deleting the Tool's token file from the operator's computer removes all data the Tool stored. Data stored by the Tool is deleted within 30 days after access is revoked.
